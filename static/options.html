Jelu Importer Settings

Credentials are stored using Firefox local storage and are not encrypted. Create a dedicated, low-privilege Jelu account if possible (note if you create an account that is separate from your primary account the "My Library" parts of the importer will not function correctly).

Authentication Method
Required Scopes:
  • books:read - For autocomplete functionality
  • books:write - For creating standalone books
  • reading:write - For adding books to your library
